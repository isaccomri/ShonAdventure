2. Library and passage builders stop after a failed scene save rather than claiming success or registering a failed save.
3. Return transitions check scene availability and show a dialogue message instead of attempting an unavailable scene load.
4. Dialogue/inventory panels have adaptive height and vertical scrolling. Completion buttons remain reachable when content exceeds panel space. World clicks are excluded from the panel and title bands. Visual confirmation is still required.
5. Doll Salon refuses stale selected items and prevents consumed photo, eye and keys from being collected again in the same room visit.

## Remaining development gaps found in code

- Room puzzle state is held in component fields and resets on unloading/reloading a room. A shared save/session-state design is required before implementing persistent backtracking.
- Salon movement is direct MoveTowards with simple leg swings; Library uses a capsule placeholder. Neither performs obstacle-aware pathfinding. Passage capsules have no movement controller.
- These rooms do not integrate with ShonQuestProgress. The design lists 20 quests; that does not mean 20 playable quests are implemented.
- Only the Salon attempts to load optional Hebrew voice clips. Voice assets are not present in this checkout. Library and Passage dialogue have no voice playback implementation.
- The licensed Adventure Creator source is deliberately excluded, so a full checkout cannot be treated as a complete licensed project. Existing AC references must be validated on the licensed local installation.
- Hebrew shaping/RTL, small-window UI layout, raycast reachability of each object and animation appearance require visual testing.
